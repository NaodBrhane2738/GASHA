# Competition Scope & Boundaries

> **ROLE / OWNERSHIP**: Product Leads & System Architects  
> **OBJECTIVE**: Define clear MVP boundaries and explicit exclusions for the competition demo.

---

## Strictly In-Scope
- Vercel & GitHub environment discovery and asset normalization
- Active Digital Twin security graph
- Deterministic Security Assessment & Risk Scoring engine
- Graph-based Attack-Path calculation
- Live telemetry ingestion from `apps/demo-target` via `@gasha/telemetry-sdk`
- Deterministic Detection and Incident Correlation
- Evidence-grounded AI attack storytelling and response recommendations
- Controlled allowlisted response execution (`BLOCK_SOURCE`, `DISABLE_SESSION`, `ISOLATE_RESOURCE`)
- Closed-loop adaptive state mutation and immediate recalculation

## Strictly Out-of-Scope (Excluded for MVP)
- Multi-cloud enterprise sprawl (AWS/GCP/Azure simultaneous full discovery)
- Active Directory / Windows endpoint EDR agents
- Dynamic malware binary detonation / sandboxes
- Unconstrained autonomous agents executing arbitrary bash commands
